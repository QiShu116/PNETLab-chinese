# PNETLab-chinese
通过油猴脚本汉化PNETv8

基于PNetLab-27H1-v8.2-6.8.93resolute1汉化

主要采用机翻，可能有部分翻译错误

汉化不全但是可以覆盖基本使用，后续再更新优化

## 使用方法
将脚本以下两个字段的127.0.0.1修改为PNETLab服务器的IP地址后导入油猴即可

```
// @match        http://127.0.0.1/*
// @match        https://127.0.0.1/*
```
